# Duolingo Mission Console — Day 1–6 Work

This private repository is for the **Doomsday Protocol Mission Console** work only. It contains the Day 1–6 saved worksheet values, practice datasets, exported L4/L5 Google Sheets, and related workbooks/presentations.

Start with [`MISSION_CONSOLE_EXPORTS.md`](MISSION_CONSOLE_EXPORTS.md) for the day-by-day activity status and file inventory, [`Mission-Console-Activity-Results.csv`](Mission-Console-Activity-Results.csv) for sortable activity scores/statuses, and [`Mission-Console-Evidence-URLs.csv`](Mission-Console-Evidence-URLs.csv) for the saved evidence/source URLs.

## Day folders

- `Day-01/` — M1-1 and GS-2 worksheet export; recorded M1-2 touchpoint CSV, clearly marked as legacy LinguaLeap data.
- `Day-02/` — M1-3 GA4 demo answers and UTM/journey-map notes.
- `Day-03/` — D1 web-practice CSV and M2-1 listening/dashboard worksheet notes.
- `Day-04/` — M2-2 ad/keyword export, M2-3 privacy checklist, L4 source workbook, D2/D3 practice data and concept ad.
- `Day-05/` — M3-1 results, L5 source workbook, D4/D5 practice data, CRM/model outputs and report deck.
- `Day-06/` — L6 saved plan values and presentation files.

## Data note

D1–D5 files are fictional classroom practice datasets, not Duolingo's real analytics or campaign data. Google Merchandise Store numbers in Day 2 are from Google's demo account. Review the Day 1 touchpoint notes for Duolingo brand consistency before reusing them. No unrelated coursework or personal documents are included.

`L4_Power_Campaign_Console_Copy.xlsx` and `L5_Time_Loop_Console_Copy.xlsx` are direct Excel exports of the saved Google Sheets, with their tabs intact. The original Google Sheets links are included above for reference; the repository also stores the sheet files themselves.
